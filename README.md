# Surplus Into Smile — Frontend Website

A responsive, static HTML/CSS/vanilla JavaScript website for a food donation and rescue initiative.

## Run locally
Open `index.html` in a browser, or run `npx serve .` from this folder.

## Deploy to Vercel
1. Push the contents of this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Framework Preset: **Other**.
4. Build Command: leave blank.
5. Output Directory: `.`.
6. Deploy.

No backend, build step or environment variables are needed for this frontend-only version.

## Customize

- Impact counters are illustrative sample values and are labelled as such.

## Scope
This is a frontend-only informational website. Donation forms, user accounts, live donation inventory, NGO requests, admin management and notifications are not connected to a database or backend.
